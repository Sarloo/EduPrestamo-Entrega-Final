# Unit-test evidence

Regenerate with `npm ci` followed by:

```text
npm run test:coverage -- --ci --coverageThreshold='{"global":{"branches":80,"functions":80,"lines":80,"statements":80}}'
```

The command must exit successfully. Preserve the generated LCOV/HTML/JSON
coverage artifacts from `reports/coverage/` or download the `jest-coverage-*` artifact
from the final GitHub Actions run. Record the final percentages and commit SHA;
do not type percentages that were not generated by Jest.
