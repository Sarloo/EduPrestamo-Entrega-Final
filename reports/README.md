# Reproducible evidence

This directory is the index for evidence generated by the exact source commit
submitted for evaluation. The README files are instructions only; they are not
test or security results.

Do not invent, hand-edit, or reuse metrics from another commit. Every final
summary should identify the Git commit, date, command, tool version, result,
findings, remediation, and revalidation status. GitHub Actions also publishes
the raw reports as immutable run artifacts.

Expected evidence:

- `unit/`: Jest coverage and test summary.
- `security/zap/`: ZAP HTML, JSON, and Markdown reports plus remediation notes.
- `quality/sonarqube/`: exported Sonar measures and Quality Gate evidence.
- `cicd/`: final workflow run URL and stage results.
- `deployment/`: image, healthcheck, and staging smoke-test evidence.
